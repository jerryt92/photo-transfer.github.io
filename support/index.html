常见问题

Frequently Asked Questions

为什么需要照片图库权限？

PhotoTransfer 需要照片图库权限来添加导入内容、读取你选中并导出的媒体、创建或复用 PhotoTransfer 相册，以及检查重复项目。

为什么需要从“文件”App 选择文件或文件夹？

iOS 只允许应用读取你明确授权的位置。PhotoTransfer 只会读取你通过系统文件选择器选择的文件或文件夹。

如何备份到外接 SSD？

先将 SSD 连接到 iPhone 或 iPad。在导出页选择相册媒体后，打开系统文件夹选择器，并在“浏览”中选择 SSD 上的目标文件夹。请保持 SSD 连接，直至任务完成。

如何从 SSD 或“文件”App 导入？

在导入页通过系统文件选择器选择 SSD 或“文件”App 中的文件或文件夹，等待扫描完成后开始导入。照片、视频以及可匹配的照片与 MOV 文件均可处理。

实况照片如何合并？

应用会扫描可导入项目，尝试匹配照片与对应的 MOV 文件，并把匹配结果导入为系统相册中的实况照片。

如何导出到“文件”App？

在导出页选择系统相册中的照片、视频或实况照片，再选择“文件”App 或外接 SSD 中的目标文件夹。可在设置中选择按年 / 月创建子目录，或不创建子目录。

传输时可以离开 App 吗？

导入或导出过程中请尽量保持 PhotoTransfer 运行。支持实时活动的设备可以在锁屏或灵动岛查看进度，但长时间后台运行仍可能受系统限制。

如何减少重复导入？

在设置中开启“跳过已重复导入的项目”。应用会检查 PhotoTransfer 相册中的已有媒体，帮助减少重复导入。

为什么部分 iCloud 照片无法立即预览或导出？

仅存储在 iCloud 的媒体需要由系统先下载到设备。请确认网络连接可用，并在资源下载完成后重试。PhotoTransfer 不会将媒体上传到开发者服务器。

Why does PhotoTransfer need photo library permission?

PhotoTransfer needs photo library permission to add imported content, read media you select for export, create or reuse PhotoTransfer albums, and check duplicate items.

Why do I need to pick files or folders from Files?

iOS only allows apps to read locations you explicitly authorize. PhotoTransfer reads only files or folders selected through the system file picker.

How do I back up to an external SSD?

Connect the SSD to your iPhone or iPad. On the Export screen, select library items, open the system folder picker, and choose a destination folder on the SSD under Browse. Keep the SSD connected until the transfer finishes.

How do I import from an SSD or Files?

On the Import screen, use the system file picker to select files or folders on your SSD or in Files. After scanning finishes, start the import. Photos, videos, and matching still-photo and MOV pairs can be processed.

How are Live Photos rebuilt?

The app scans importable items, matches still photos with corresponding MOV files, and imports matched pairs as Live Photos in the system photo library.

How do I export to Files?

On the Export screen, select photos, videos, or Live Photos from your library, then choose a destination folder in Files or on an external SSD. In Settings, choose year / month subfolders or no subfolders.

Can I leave the app while transferring?

Please keep PhotoTransfer running while importing or exporting. Devices with Live Activities can show progress on the Lock Screen or Dynamic Island, but long-running background work may still be limited by the system.

How do I reduce duplicate imports?

Turn on “Skip already imported items” in Settings. The app checks existing media in the PhotoTransfer album to help reduce repeated imports.

Why can’t some iCloud items be previewed or exported right away?

Items stored only in iCloud must first be downloaded to your device by the system. Check your network connection and try again after the resource has downloaded. PhotoTransfer never uploads your media to developer-operated servers.

问题反馈

Report an Issue

反馈前，请先打开“设置”→“高级”，等待诊断包准备完成后，点击“分享全部诊断 ZIP 包”并将文件附在邮件中。这有助于我们更快定位问题。诊断 ZIP 不包含照片、视频、实况照片或其他媒体文件，也不会自动上传；其中仅含近期应用运行日志和设备技术信息。

邮件中请同时附上以下信息：

  • 设备型号和 iOS 版本
  • PhotoTransfer 版本号
  • 问题发生在选择文件、扫描、导入、导出、权限还是实时活动阶段
  • 是否包含实况照片、视频或大量文件

如果您愿意，可以提供出现问题的媒体原件，这能够更快地帮助我们定位问题。

  • 导出问题：原片导出方式请参考 Apple 官方教程。
  • 导入问题：请提供导入前的源文件；实况照片请同时提供照片与对应的 MOV 文件。

问题反馈邮箱：jerrytian92@outlook.com

Before reporting an issue, open Settings → Advanced. Once the diagnostics archive is ready, tap “Share Full Diagnostics ZIP” and attach the exported file to your email. This helps us investigate more quickly. The diagnostics ZIP does not include your photos, videos, Live Photos, or other media files, and it is never uploaded automatically; it contains only recent app logs and technical device information.

Please also include:

  • Device model and iOS version
  • PhotoTransfer version
  • Whether the issue happens during file selection, scanning, importing, exporting, permissions, or Live Activities
  • Whether the import includes Live Photos, videos, or a large number of files

If you’re willing, you can provide the original media that triggers the issue. This can help us investigate more quickly.

  • Export issues: See the official Apple guide for exporting the original.
  • Import issues: Provide the source file before import; for a Live Photo, include both the still image and its matching MOV file.
