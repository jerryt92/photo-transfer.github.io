PhotoTransfer Privacy Policy

Last updated: August 17, 2026.

概述

PhotoTransfer 尊重你的隐私。应用的核心功能是在“文件”App 与系统照片图库之间导入和导出照片、视频及实况照片资源。

PhotoTransfer 不会收集、出售、共享或上传你的个人数据、照片、视频或文件。

我们访问哪些数据

  • 你选择的文件或文件夹：应用只会访问你通过系统文件选择器授权的位置，用于读取待导入媒体或写入你选择导出的媒体。
  • 照片图库：应用请求照片图库权限，用于向系统相册添加导入内容、读取你选择导出的媒体、创建或复用 PhotoTransfer 相册，并在开启跳过重复项目时检查已有媒体。
  • iCloud 照片资源：当你选择的照片或视频仅存储在 iCloud 中时，应用会通过 Apple 的系统照片图库服务下载该资源，以便预览或导出。
  • 本地设置：应用会在设备本地保存你的偏好设置，例如相册命名方式、是否跳过重复项目、是否跳过视频及视频大小阈值。
  • 传输进度：应用会在界面、锁屏实时活动或灵动岛中显示当前导入或导出的进度、文件名、成功数、失败数和传输速度等状态信息。

我们如何使用这些数据

  • 读取你授权的文件或文件夹，识别照片、视频和可合并为实况照片的素材。
  • 将媒体导入系统照片图库，或将你选择的照片图库媒体导出到授权文件夹。
  • 检测重复项目，以减少重复传输。
  • 在本机显示导入和导出进度及结果。
  • 在需要时通过 Apple 的系统服务获取你已选择的 iCloud 照片或视频资源。

不会进行的行为

  • 不会将你的照片、视频或文件上传到开发者服务器。
  • 不会出售或共享你的个人数据。
  • 不会用于广告追踪。
  • 不会使用第三方分析 SDK 收集使用行为。
  • 不会在未经你通过系统授权的情况下读取文件或照片图库。

数据存储

导入的媒体保存在你的系统照片图库中；导出的媒体保存在你选择的文件夹中。应用偏好设置保存在设备本地。PhotoTransfer 不运营用于接收或存储用户媒体内容的服务器。

权限说明

  • 照片图库权限：用于添加导入内容、读取选中后导出的媒体、创建或复用 PhotoTransfer 相册，以及检查重复项目。
  • 文件访问权限：通过系统文件选择器授予，仅用于读取待导入文件或写入你选择导出的文件夹。
  • 实时活动：用于在锁屏或灵动岛展示传输进度。显示内容来自本机任务。
  • 无线数据：在部分设备或系统配置中，系统可能要求允许应用使用无线数据。该访问仅用于通过 Apple 的系统照片图库服务下载你选择的 iCloud 照片或视频资源；PhotoTransfer 不会将你的媒体上传至开发者服务器，也不会收集网络使用数据。

关于“无线数据”系统提示

部分 iPhone 或 iPad 的系统设置会为 App 提供“无线数据”控制。PhotoTransfer 使用该访问的唯一目的，是在你主动浏览、预览或导出存储于 iCloud 的照片和视频时，让 Apple 的系统照片图库服务下载所需资源。

拒绝此访问不会影响本机已下载资源的导入、浏览或导出；但尚未下载到设备的 iCloud 照片和视频可能无法加载。PhotoTransfer 不运营媒体服务器，不会将你的照片、视频或网络使用信息发送给开发者。

儿童隐私

PhotoTransfer 不面向儿童收集个人数据，也不会主动收集任何年龄信息。

政策变更

如果未来版本增加会影响隐私的数据处理方式，本页面会更新相应说明，并修改“最后更新”日期。

Overview

PhotoTransfer respects your privacy. The app is built to import and export photos, videos, and Live Photo resources between Files and the system photo library.

PhotoTransfer does not collect, sell, share, or upload your personal data, photos, videos, or files.

Data the app may access

  • Files or folders you select: The app accesses only locations you authorize through the system file picker, to read media for import or write media that you choose to export.
  • Photo library: The app requests photo library permission to add imported content, read media you select for export, create or reuse PhotoTransfer albums, and check existing media when duplicate skipping is enabled.
  • iCloud photo resources: When a photo or video you select is stored only in iCloud, the app can download that resource through Apple’s system photo library service so it can be previewed or exported.
  • Local settings: The app stores preferences on your device, such as album naming, duplicate skipping, video skipping, and video size thresholds.
  • Transfer progress: The app may show local import or export status, including file name, progress, successful items, failed items, and transfer speed in the app, Live Activities, or Dynamic Island.

How the data is used

  • To read authorized files or folders and identify photos, videos, and resources that can be rebuilt as Live Photos.
  • To import media into the system photo library or export selected library media to authorized folders.
  • To detect duplicate items when the duplicate skipping option is enabled.
  • To display import and export progress and results locally on your device.
  • When needed, to obtain iCloud photo or video resources you select through Apple’s system services.

What the app does not do

  • It does not upload your photos, videos, or files to developer-operated servers.
  • It does not sell or share your personal data.
  • It does not use your data for advertising tracking.
  • It does not use third-party analytics SDKs to collect usage behavior.
  • It does not read files or the photo library without system-granted permission.

Data storage

Imported media is stored in your system photo library, while exported media is stored in the folder you select. App preferences are stored locally on your device. PhotoTransfer does not operate servers for receiving or storing user media.

Permissions

  • Photo library permission: Used to add imported content, read media you select for export, create or reuse PhotoTransfer albums, and check duplicate items according to your settings.
  • File access permission: Granted through the system file picker and used only to read import files or write to the folder you select for export.
  • Live Activities: Used to show transfer progress on the Lock Screen or Dynamic Island. The displayed information comes from the local task.
  • Wireless data: On some devices or system configurations, iOS may ask you to allow wireless data access. This is used only for Apple’s system photo library service to download iCloud photos or videos that you select. PhotoTransfer does not upload media to developer-operated servers or collect network-usage data.

About the "wireless data" system prompt

Some iPhone or iPad system configurations provide a per-app “wireless data” control. PhotoTransfer uses this access only when Apple’s system photo library service needs to download an iCloud photo or video that you actively choose to browse, preview, or export.

Denying this access does not affect importing, browsing, or exporting media already downloaded to your device. However, iCloud photos and videos that have not been downloaded may not load. PhotoTransfer does not operate media servers and does not send your photos, videos, or network-usage information to the developer.

Children's privacy

PhotoTransfer does not knowingly collect personal data from children and does not request age information.

Changes to this policy

If a future version changes how privacy-related data is handled, this page will be updated and the “Last updated” date will be revised.
